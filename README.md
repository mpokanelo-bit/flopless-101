# Discover Lesotho - Tourism Website

A responsive Lesotho tourism website built for an HTML5, CSS3, Bootstrap 5 and JavaScript assessment.

## Pages
- Home
- About
- Destinations
- Gallery
- Contact & Booking

## Technologies
- HTML5 semantic elements
- CSS3
- Bootstrap 5
- JavaScript
- LocalStorage

## JavaScript Features
1. Dark/light mode
2. Destination search
3. Destination category filtering
4. Gallery lightbox
5. Gallery next/previous navigation
6. Booking cost calculator
7. Contact form validation
8. Booking form validation
9. Registration/password validation
10. LocalStorage for theme and latest booking

## Bootstrap Components
- Responsive Navbar
- Cards
- Carousel
- Modal
- Accordion
- Alerts
- Buttons
- Forms
- Badges
- Responsive containers/rows/columns

## Running the project
Open `index.html` in a browser. An internet connection is useful because Bootstrap 5 is loaded from the official jsDelivr CDN.

## Note about images
The included SVG assets are lightweight original student-project illustrations so the website works without needing a separate image download. They can be replaced later with properly licensed tourism photographs.

## Navigation
All five pages use explicit relative links (`./index.html`, `./about.html`, etc.) so they remain connected when the project is opened from the extracted project folder. The navigation is positioned at the top-left on desktop and collapses into Bootstrap's mobile menu on smaller screens.
